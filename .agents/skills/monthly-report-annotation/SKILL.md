# 月度经营分析报告 Excel 批注标准工作流 (Monthly Management Report Annotation Skill)

本 Skill 沉淀并规范了针对企业月度经营分析报告（`[YYYY]年[MM]月_经营分析报告.xlsx`）的多维度数据诊断与 Excel 批注自动化注入流程。用于月度结账后，自动或半自动对全套报表进行深入归因分析，并在对应单元格插入专业、美观、格式化的高管层批注（Excel Comments）。

## 🛠️ 六大模块标准批注流程与诊断框架

### 模块一：利润表（费用与利润异常项）批注流程

#### 1. 数据排查标准
1. 读取 `费用异常明细` 及 `费用分析` 中的“B. 费用科目环比矩阵（重点）”，筛选异常评分 $\ge 30$ 的所有科目；
2. 调取 `费用明细`，按部门、科目、摘要、金额聚合，找出导致异常变动的具体大额报销单据（如：跨期补发历史提成、大额社保红字冲回、年度固定年税/保险、到港提柜文件费等）；
3. 计算当期主营毛利与剔除偶发性跨期费用后的“还原经营性营业利润”。

#### 2. 批注模板规范
```text
【[科目名称] [异常属性标签]（评分 [分值]）】
• 本期金额：[X] 元 | 上期金额：[Y] 元
• 环比变动：[+/-A] 元（[+/-B]%） | 同比变动：[+/-C] 元（[+/-D]%）

【明细构成（主要单据）】
1. [报销事由/项目1]：[金额] 元（[性质说明]）
2. [报销事由/项目2]：[金额] 元
...

【归因说明与管理评价】
[阐述该项波动的业务根源，说明属于一次性偶发、跨期摊销、会计冲销还是常态化增长，以及对当期利润的实际影响]
```

---

### 模块二：按品类汇总（按月）批注流程

#### 1. 分析维度
1. **量价拆解**：销量变动率 vs 平均售价（ASP）变动率，识别是“以价换量”还是“结构升级”；
2. **盈利质量**：毛利率升降点数（pp）及毛利贡献占比，识别利润引擎品类；
3. **爆款驱动**：结合 `明细_销售与库存` 提取各品类 Top 5 利润贡献单品。

#### 2. 批注模板规范
```text
【[品类名称]-当月深度分析（[战略定位]）】
• 本期毛利：[X] 元（环比 [+/-A]%，同比 [+/-B]%）
• 毛利率：[C]%（环比 [+/-D] pp） | 毛利贡献率：[E]%
• 销售收入：[Y] 元（占比 [F]%） | 销售均价：[G] 元/件（环比 [+/-H]%）

【核心爆款单品驱动】
1. [型号1] [名称]：销量 [N] 台，创收 [R] 万元，贡献毛利 [P] 万元（毛利率 [M]%）；
2. [型号2] [名称]：...
前五大爆款合计贡献该品类 [K]% 毛利。
```

### 模块三：按产品汇总_含合计（产品健康与矩阵）批注流程

#### 1. 产品分级归类规则（6大维度）
* **维度 1：全盘大盘（A2 合计行）**：总营收、总毛利、综合毛利率、总库存量、总存货金额及存货周转天数。
* **维度 2：核心创利冠军（Top Profit Champions）**：年毛利前 10 名单品（如 BC-430、PW-210、RB-YJ-5424、RWD10.0GFE）。
* **维度 3：巨额资金滞销积压（High Stock Stagnation Risk）**：库存金额大但年销量极低/为 0 的产品（如焊机 US/MMA-280BIVOLT、MMA-250D、RBYJ-5424、锂电池包 BA20V-3.0A、大量积压配件 BC-430杆子）。
* **维度 4：畅销断货/补货预警（Stockout Alerts）**：近 3 月热销但库存 $\le 1$ 台的机型（如 RWD3.0GF-3500、USK-H6250iE、USK-H3150iS、MGX-210L）。
* **维度 5：负毛利倒挂亏损（Negative Margin Items）**：毛利率 $< 0$ 的甩卖/清仓品（如 BY-2210233-2、BY-2211013AN、EA-521broca）。
* **维度 6：超高毛利率明星（High Margin Stars）**：毛利率 $> 50\% \sim 80\%$ 且毛利额可观的单品（如 RWD10.0GF-12000、4SDM310-2）。

---

### 模块四：仪表盘（Dashboard KPI Cards）批注流程

#### 1. 卡片与预算表覆盖点
1. **主营业务收入（A5 / B35）**：营收规模、同环比增长率、核心品类拉动占比；
2. **净利润 & 营业利润（E5 / Q5 / B36）**：表观利润 vs 剔除偶发跨期费用后的“还原经营性利润”；
3. **成本率 & 净利率（M5 / I5 / B37 / B38）**：毛利空间优化幅度、品类结构升级影响；
4. **期间费用率（A9 销售 / E9 管理 / Q9 财务 / B39~B41）**：异常费率预警原因（如管理费用率因补发历史提成跃升至 15.24%）；
5. **双高资金占用（I9 应收 / M9 存货 / B13 周转天数）**：DSO 账期风险、存货资金沉淀与去化压力。

---

### 模块五与六：应收账款账龄与客户贡献回款批注流程

#### 1. 客户信用与账龄诊断标准
* **120天以上超长账龄占比 $\ge 50\%$**：标记为 **【严重超期 / 信用风险 🚨】**，如 DEPORTIVOS AIKA CA、IMPORTADORA TEMPONOVO、CUGRANCA；
* **DSO 回款天数 $\ge 200$ 天**：标记为 **【回款周期过长 / 赊销依赖 ⚠️】**；
* **DSO $\le 30$ 天 或 账面为负数（预付款）**：标记为 **【现款现结 / 黄金标杆客户 🟢】**，如 SANTAFE SPORT、SUPERMERCADO LUZ、JILIN CHONG。

## 💻 openpyxl 批注生成技术规范与脚本定式

在执行批量批注注入时，为避免 Windows 终端中文传参截断或特殊字符异常，**必须编写独立的 Python 脚本并执行**。

### 脚本标准模版
```python
# -*- coding: utf-8 -*-
import openpyxl
from openpyxl.comments import Comment

file_path = r'G:\Users\123\Documents\GitHub\ecount-system\基础数据\基础数据\[YYYY]年[MM]月_经营分析报告.xlsx'
wb = openpyxl.load_workbook(file_path)

# 示例：针对指定工作表写入批注字典
comments_map = {
    'SheetName': {
        'CellCoordinate': 'Comment Text Content...',
    }
}

for sname, cdict in comments_map.items():
    if sname in wb.sheetnames:
        ws = wb[sname]
        for coord, txt in cdict.items():
            comment = Comment(txt, '经营分析系统')
            lines = txt.splitlines()
            max_len = max(len(l) for l in lines) if lines else 20
            # 动态计算自适应宽度与高度，确保文字完整显示不被遮挡
            comment.width = max(380, min(550, max_len * 15))
            comment.height = max(180, len(lines) * 19 + 30)
            ws[coord].comment = comment

wb.save(file_path)
print("Successfully inserted all comments!")
```

## ✅ 月度批注校验检查清单 (Verification Checklist)

每月批注工程完成后，需运行快速验证脚本确保：
1. ✅ **无批注遗漏**：`利润表`、`按品类汇总(按月)`、`按产品汇总_含合计`、`仪表盘`、`应收账款账龄分析`、`客户贡献与回款` 均已成功注入批注；
2. ✅ **坐标对齐准确**：批注位置与当月数据列（如 7月对应 C 列/F列/AR列/BK列/Y列）完全匹配；
3. ✅ **格式与排版规范**：批注弹窗尺寸自适应（宽度 380~550px，行高 19px），无文字溢出或换行错乱；
4. ✅ **文件完整性**：保存后的 Excel 文件可正常打开，各公式、透视表及动态图表完好无损。
